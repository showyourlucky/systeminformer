# 待汉化文本全量审计方案

本文档用于审计当前 `tools/translate/output/review_required.json` 中的待汉化文本，目标是从全量待汉化集合里识别并排除“不应人工翻译”的技术名词、协议标识、产品名、格式片段和机器可解析文本，同时避免误排真实 UI 文案。

## 背景

当前已经提取出待汉化内容，但这只表示每条字符串都被规则归类为“待汉化”或“已排除”，不等于“待汉化集合全部都应该翻译”。

待汉化集合中可能仍混有以下内容：

- 用户可见但应保留原文的产品名、平台名、协议名和硬件标准名。
- 规格表、枚举表、性能计数器表中的固定英文标识。
- 占位值、单位、短格式片段和诊断 token。
- 因宽泛 i18n 规则命中而进入待汉化的技术短文本。

## 流程
1. 执行`python scripts/filter_pending_review.py  --limit 20`, 然后从`F:\C\systeminformer\tools\translate\output\pending_review.json`获取待验证的内容
2. 根据pending_review.json读取文件源码, 判断对应source的值是否需要汉化, 如果源码相近可以合并判断, 不确定时读取更多的源码进行判断
  * 必须汉化: 执行`python scripts/confirm_one.py $id`, $id为文件的内容中的id
  * 不用汉化: 提取排除规则, 把规则加入到F:\C\systeminformer\tools\translate\rules\exclude_rules.json
3. 每10个批次把`F:\C\systeminformer\tools\translate\rules\exclude_rules.json`和`F:\C\systeminformer\tools\translate\output\certain_i18n.json`提交到git
4. **重复1操作, 直到pending_review.json没有新内容**

## 注意事项

- 执行`python scripts/confirm_one.py $id`时可以批量提交(确认都是待翻译的)
- 不要偷懒, 认真对待每一批待验证的内容, 避免出现批量提交后面发现实际不应该翻译而是加排除规则
- 待审核内容非常多，但也不需要优化策略, 老老实实安装流程走

## 成功标准

- 每条新增排除规则都有明确源码上下文、命中样本和排除理由。

- 不因短文本、全大写或含符号等单一特征直接排除真实 UI 文案。

- 新增规则命中后，验证不包含菜单、按钮、列名、状态说明、错误提示等应汉化文本。

- 完整性检查、`py_compile`


## 重点检查以下误标类型：

1. DLL、EXE、SYS、PDB、LIB、MUI 等文件名。
2. Windows API、NT API、函数名、结构体字段名。
3. 注册表路径、注册表键名、注册表值名。
4. NT 对象路径，例如 `\Device\`、`\Driver\`、`\BaseNamedObjects\`。
5. 命令行参数，例如 `-install`、`-silent`、`/debug`。
6. 服务名、驱动名、内部对象名。
7. 权限名、SID、账户名、对象名，例如 `SeDebugPrivilege`、`NT AUTHORITY\SYSTEM`。
8. GUID、CLSID、协议名、MIME 类型。
9. 文件扩展名、路径片段、环境变量。
10. 窗口类名、控件类名，例如 `Button`、`Static`、`SysListView32`。
11. 配置项 key、JSON key、INI key、枚举值、状态值。
12. 纯格式化字符串或技术格式字符串，例如 `%s`、`%lu`、`0x%Ix`。
13. 调试标识、日志标签、内部 tracing 文本。
14. 版权、公司名、原始文件名、产品内部名称。
15. 不是直接展示给用户看的标识符类字符串。
16. 纯数字或者数字+符号组合, 例如`10`、`10%`、`10-10`

## 规则编写原则

规则组合约束方法：
  `pattern`：限制字符串内容。
  `path_pattern`：限制文件或目录, 尽量少用, 不要为了“保险”滥用 `path_pattern`。如果判断是跨文件通用技术名，应优先只用 `pattern`。。
  `source_line_pattern`：限制源码调用上下文。
  `file_types`：限制扩展名。
  示例

  ```
  {  "id": "I18N-C-EXAMPLE-PAGE-TEXT",
    "name": "C 示例页面文本",
    "type": "待汉化规则",
    "file_types": [".c"],
    "pattern": "",
    "path_pattern": "^plugins/Example/page\\.c$",
    "source_line_pattern": "(?:PhAddListViewColumn|PhAddListViewItem|PhCreateEMenuItem|PhShow)",
    "description": "提取示例页面中的列名、列表项、菜单和提示文本。",
    "reason": "这些字符串会显示在示例页面 UI 中，属于用户可见文案。",
    "enabled": true
  }
  ```

注意：

- 规则默认忽略大小写。
- 技术缩写必须使用 `(?-i:...)` 避免误伤大小写不同的 UI 文本。

### 完整性检查

```powershell
$env:PYTHONIOENCODING = 'utf-8'
@'
import json
from collections import Counter
from pathlib import Path

root = Path("tools/translate")
records = json.loads((root / "codex/analysis_records.json").read_text(encoding="utf-8"))["records"]
i18n_rules = json.loads((root / "rules/i18n_rules.json").read_text(encoding="utf-8"))["rules"]
exclude_rules = json.loads((root / "rules/exclude_rules.json").read_text(encoding="utf-8"))["rules"]

i18n_ids = [item["id"] for item in i18n_rules]
exclude_ids = [item["id"] for item in exclude_rules]
i18n_id_set = set(i18n_ids)
exclude_id_set = set(exclude_ids)

checks = {
    "i18n_duplicate_ids": sorted({rule_id for rule_id in i18n_ids if i18n_ids.count(rule_id) > 1}),
    "exclude_duplicate_ids": sorted({rule_id for rule_id in exclude_ids if exclude_ids.count(rule_id) > 1}),
    "missing_status": [item["id"] for item in records if not item.get("status")],
    "missing_reason": [item["id"] for item in records if not item.get("reason")],
    "i18n_missing_rule": [item["id"] for item in records if item["status"] == "待汉化" and not item.get("i18n_rule_id")],
    "exclude_missing_rule": [item["id"] for item in records if item["status"] == "已排除" and not item.get("exclude_rule_id")],
    "unknown_i18n_rule": [item["i18n_rule_id"] for item in records if item.get("i18n_rule_id") and item["i18n_rule_id"] not in i18n_id_set],
    "unknown_exclude_rule": [item["exclude_rule_id"] for item in records if item.get("exclude_rule_id") and item["exclude_rule_id"] not in exclude_id_set],
}

print("状态统计:")
for status, count in Counter(item["status"] for item in records).items():
    print(status, count)

failed = False
for name, values in checks.items():
    print(name, len(values))
    if values:
        failed = True

if failed:
    raise SystemExit(1)
'@ | python -
```

## 风险与边界

- 不追求把所有英文短词都排除。短词很多是真 UI，例如 `Open`、`Read`、`Copy`。
- 不追求把所有全大写词都排除。`OK` 在 RC 按钮中通常是用户可见按钮文本。
- 不把“用户可见”与“应该翻译”混为一谈。部分用户可见专名应保留原文。
- 不为降低待汉化数量牺牲可读性和上下文准确性。
- 连续三次发现规则误伤时，暂停扩大规则范围，重新回到源码上下文分析。
